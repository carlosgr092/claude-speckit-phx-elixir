# Support

Thanks for using `claude-speckit-phx-elixir`. Here is where to go:

## Questions and ideas

- **GitHub Discussions** — for questions, usage help, workflow ideas, and
  showing what you built: <https://github.com/carlosgr092/claude-speckit-phx-elixir/discussions>

## Bugs

- **Open an issue** with the Bug report template:
  <https://github.com/carlosgr092/claude-speckit-phx-elixir/issues/new/choose>

  Please include your OS, Claude Code version, Elixir/Phoenix versions, the
  `/spx:` command you ran, and what happened vs. what you expected. Running
  `/spx:doctor` and pasting its output helps a lot.

## Feature requests

- Use the **Feature request** issue template, or start a Discussion first if you
  want to shape the idea with the community.

## Documentation

- [`README.md`](README.md) — overview, install, command reference.
- [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md) — how the fusion works.
- [`CONTRIBUTING.md`](CONTRIBUTING.md) — how to contribute.
